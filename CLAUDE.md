# mechanicalai-python

The official Python library for the Mechanical AI API; setup, checks and conventions are in [CONTRIBUTING.md](CONTRIBUTING.md).
This repository is public: nothing internal, no secrets, no example keys beyond `mk_0000000000000000000000000000000000000000`.
The API contract is `spec/public-api.openapi.yaml`; the library follows it, never the other way round.
